GNITS ENGINEERS' DAY 2026 — STATIC PROMOTIONAL WEBSITE

Open index.html in a browser. No build step is required.

The site uses the supplied Engineers' Day posters as event imagery and includes decoded registration QR destinations where they could be reliably read. Items without an application QR are explicitly marked instead of inventing a link.

Files:
- index.html — page structure and event content
- styles.css — visual design / responsive layout
- script.js — event data, filters, search, modal details
- assets/posters — supplied poster artwork + rendered PDF posters
- assets/qr — clean QR images generated from decoded registration destinations
